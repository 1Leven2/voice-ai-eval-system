# 多场景语音智能体验评测与问题分析系统实施计划

> 本计划记录已批准的实现范围，执行过程中以测试结果和审查文档为准。

**目标：** 构建可本地运行的语音样例导入、量化评测、AI/规则诊断、人工修订和结构化报告系统。

**架构：** FastAPI 提供 API 和页面路由，SQLite 保存样例、评测和修订，规则引擎负责可复算指标，诊断适配器支持离线规则和可选 LLM。

**技术栈：** Python 3.10、FastAPI、Jinja2、SQLite、pytest、原生 HTML/CSS/JavaScript。

## 验收标准

1. 默认无外部 API 密钥即可启动并完成全链路演示。
2. 100 条样例可导入、评测、修订和导出，且覆盖三类场景。
3. 每条诊断都有原始证据或明确的“证据不足”标记。
4. 导入错误逐条返回，单条错误不阻断其他样例。
5. README 中的安装、启动、生成样例和测试命令可复现。
