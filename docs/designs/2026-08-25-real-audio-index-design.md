# 真实音频索引与标签设计

## 目标

将 `data/audios/` 中的真实音频纳入系统数据流，保留原始文件，同时生成可追溯的结构化样例。

## 规则

- 扫描 `.wav` 和 `.mp3` 文件，其他文件逐条报告为不支持，不阻断有效文件。
- `sample_id` 使用文件名去掉扩展名；重复 ID 逐条报告。
- `reference.label` 使用同一文件名标签，并记录 `label_source=filename`。
- `input_data.audio_path` 保存相对于项目根目录的 POSIX 路径。
- WAV 使用标准库读取时长、采样率、声道和采样宽度；MP3 无外部解码器时未知字段填写 `-`。
- `system_output` 始终为 `-`，当前阶段不把参考标签冒充模型结果。
- Demo 脚本每次先清理本地 Demo 数据库，保证重复运行不会累积旧记录。

## 结果

当前目录被索引为 43 条真实音频记录；详情页可以直接打开原始音频文件。真实音频记录没有模型输出，因此诊断结果为“证据不足/需关注”，不会参与合成样例的量化指标结论。
